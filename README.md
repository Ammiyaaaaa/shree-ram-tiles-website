# Shree Ram Tiles & Sanitary — 3D Website

A premium, mobile-friendly Next.js website for Shree Ram Tiles & Sanitary, Angul.

## Included
- Interactive Spline 3D hero showroom
- Real product images supplied for the website
- Product showcase with click-to-enlarge cards
- Generated Shree Ram Tiles & Sanitary branding/logo
- Call, WhatsApp and Google Maps buttons
- Responsive mobile/desktop design

## Run locally
1. Install Node.js 20 or newer.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local address shown by Next.js (normally http://localhost:3000)
